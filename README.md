# Portfólio — Exercício de HTML e CSS

Meu primeiro site de portfólio, feito com **HTML e CSS puros** como exercício de fundamentos de front-end.

## Páginas

- **Home** (`index.html`): apresentação com chamada principal e links para as redes sociais
- **Sobre mim** (`about.html`): página com informações sobre mim

## Conceitos praticados

- Estrutura semântica em HTML
- Estilização com CSS e organização de arquivos de estilo
- Navegação entre páginas

## Como executar

Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/RicardoLMessias/Site-Exercicio-HTMLeCSS.git
```
